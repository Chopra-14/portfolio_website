## Project Description
This is a modern responsive personal portfolio website built using Next.js, Tailwind CSS, and Framer Motion. The website showcases my skills, projects, animations, and professional profile with a clean modern UI.

---

## Features
- Fully Responsive Design
- Modern Dark UI
- Smooth Animations
- Parallax Scrolling Effect
- Animated Skills Section
- Project Showcase
- Contact Section
- Accessibility Optimizations
- SEO Optimizations

---

## Run Locally

Clone the repository

```bash
git clone https://github.com/Chopra-14/portfolio_website.git
```

Go to project folder

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```
